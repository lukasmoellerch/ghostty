Ghostty VT OSC Parser - WebAssembly Example

This example demonstrates parsing terminal OSC (Operating System Command) sequences using the Ghostty VT WebAssembly module.

Loading WebAssembly module...

Example OSC Sequences (click to try)

  • 0;hello - Change window title
  • 2;My Terminal - Change window icon name
  • 133;A - Prompt start (shell integration)
  • 133;B - Prompt end (shell integration)
  • 133;C - Command start (shell integration)
  • 133;D - Command end (shell integration)
  • 7;file:///path/to/file - Report PWD
  • 52;c;aGVsbG8gd29ybGQ= - Clipboard contents
  • 8;;id=mylink;https://example.com - Hyperlink start
  • 8;; - Hyperlink end

OSC Sequence Content

The parser runs live as you type. Full sequence would be: ESC]<content>BEL or ESC]<content>ESC\
